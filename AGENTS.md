# Basegrid working instructions

- Treat this repository as a fresh start.
- Make one small, complete change at a time.
- Do not add frameworks, services, schemas or folder layers before they are needed.
- Do not import SketchOB or previous Basegrid code or requirements without explicit approval.
- Keep Windows and macOS in mind when implementation begins.
- Record only confirmed decisions in `docs/DECISIONS.md`.
- Tool shortcuts must work on compact Windows and Mac keyboards and must not repurpose SketchUp's native shortcuts. Use Tab to cycle anchor points; preserve arrows and Shift for native inference behavior. See `docs/DECISIONS.md` for the shared keyboard conventions.
