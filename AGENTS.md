# Buildgrid working instructions

- Treat this repository as a fresh start.
- Make one small, complete change at a time.
- Do not add frameworks, services, schemas or folder layers before they are needed.
- Do not import SketchOB or previous Buildgrid code or requirements without explicit approval.
- Keep Windows and macOS in mind when implementation begins.
- Record only confirmed decisions in `docs/DECISIONS.md`.
