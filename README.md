# HQ Buildgrid

Buildgrid is starting again from a deliberately small, blank foundation.

Previous SketchOB and Buildgrid work may be consulted as reference, but it is not an active requirement. New decisions and code will be added one small step at a time.

## Folders

- `src/` — product code when the first implementation is chosen.
- `test/` — focused checks for implemented behaviour.
- `docs/` — short, confirmed decisions only.
